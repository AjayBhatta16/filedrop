About

FileDrop will help you transfer files frictionlessly with a simple 3-step process:

  1. Upload your file from the device it is currently stored on
  2. Save your 8-digit code
  3. Download the file from anywhere by entering the code on our home page

This process allows your file to be accessed from anywhere using any device. It is perfect for transferring files between devices, managing school presentations, and more!
